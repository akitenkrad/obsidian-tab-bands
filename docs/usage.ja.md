# 使い方

## 操作

| 操作 | 方法 |
| --- | --- |
| バンドを作る | タブを右クリック → 新しいバンドにまとめる |
| バンドに追加 | タブをチップにドロップ / **バンドのメンバーに挟まれた位置へドラッグ** / タブを右クリック → バンド「〜」に追加 |
| 新規タブの自動参加 | バンドのメンバーに挟まれた位置に開く / **バンドのメンバーをアクティブにしたまま新しいタブを開く** |
| バンドから外す | タブを右クリック → バンドから外す |
| 折りたたむ / 展開 | チップをクリック．畳んだ状態ではタブのタイトル部分クリックでも可 |
| 名前・色の変更，解除，一括クローズ | チップを右クリック |
| ペインへ移動 | チップを右クリック → ペイン N へ移動 / 新しいペインへ移動 |
| バンドごとドラッグ移動 | **畳んだ状態で**タブをドラッグ (同一ペイン内・ペイン間とも可) |
| コマンド | 「アクティブタブを新しいバンドにまとめる」など 4 つ |

UI の文言は**既定が英語**で，Obsidian の表示言語が日本語のときだけ日本語になる
(`src/i18n.ts`)．本ページの表記は日本語表示のもの．

## バンドの名前

新しいバンドの名前は `Tab-1`, `Tab-2`, ... の連番が既定で入る．採番は未使用の最小番号を
選ぶので，バンドを消すとその番号は再利用される．名前は空にもできる (無名バンドのチップは
色ドットだけになるが，`Tab-X` 相当の幅は確保するのでドットだけに潰れない)．

## 新規タブが自動でバンドに入る条件

バンドのメンバーに**挟まれた位置**に新しいタブを開くと，自動的にそのバンドに入る．
バンド**末尾のメンバー**をアクティブにしたまま新しいタブを開いた場合も同じ
(Chrome と同じ挙動)．

どちらも**そのとき新しく開かれたタブ**に限る．既存タブを動かしただけでは参加しない．
位置だけから推論すると誤吸収が起きるため ([内部構造](internals.ja.md) を参照)．

## 設定

設定 → コミュニティプラグイン → **Tab Bands** の歯車から開く．

| 項目 | 既定 | 内容 |
| --- | --- | --- |
| バンド名の幅 | 12 | チップに出すバンド名の最大幅 (文字数，4〜32)．テーマの都合でタブ列が窮屈なときは短くする．超えた分は省略記号になる (無名バンドのチップは影響を受けない) |
| 新しく開いたタブを吸収する | on | 上記の自動参加を 2 つまとめて切る．切ると，バンドへの追加はドラッグか右クリックメニューだけになる |

これ以外は固定．新しいバンドの色は未使用色の自動割り当て，折りたたみ時の表示は
「バンド名 (N)」．理由は[内部構造](internals.ja.md)に書いてある．設定はバンドと
同じ `data.json` に保存される．

## 既知の制限

- チップ自体のドラッグでバンドごと並び替え (親タブの `dragstart` と競合する)
- モバイル．`isDesktopOnly` は `true`．対応するには `WorkspaceMobileDrawer` の分岐が要る

## 先行プラグイン

- **Group Tabs** — 複数ファイルを 1 つのネイティブタブに束ねる方式
- **Working tabs** — バンドを「作業スペース」として左サイドバーで管理する方式
- **Tab Shifter** — 非公式 API でタブをタブグループ間に移動する
